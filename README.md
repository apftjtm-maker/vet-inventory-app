# 동물병원 재고·자동발주 체크 웹앱

동물병원 재고를 품목별로 관리하고, 현재고가 안전재고 이하로 내려간 품목을 자동으로 판단해 거래처별 발주서를 만들어 주는 단일 HTML 앱입니다.

**바로 열기 →** https://apftjtm-maker.github.io/vet-inventory-app/

- 설치 없이 브라우저에서 바로 실행됩니다. 외부 라이브러리·서버·인터넷 연결 없이 한 파일로 동작합니다.
- 입력한 값은 **그 브라우저의 localStorage**에만 저장되고 서버로 보내지 않습니다. 새로고침하거나 창을 닫았다 열어도 그대로 남습니다.
- 처음 열면 예시(샘플) 품목이 들어 있고, **초기 샘플로 리셋** 버튼으로 언제든 되돌릴 수 있습니다.
- 휴대폰·태블릿·PC 화면 폭에 맞춰 배치가 바뀝니다.

## 화면

- **요약**: 전체 품목 수, 발주 필요 품목 수, 예상 발주 금액
- **재고 목록**: 품목·거래처, 현재고/안전재고, 수량 조절, 검색·거래처 필터·"발주 필요만" 보기
- **새 품목 추가**: 품목명, 거래처, 규격/포장, 발주 단위, 현재고, 안전재고, 1회 발주수량, 단가
- **자동 발주 목록**: 현재고 ≤ 안전재고인 품목을 거래처별로 묶어 발주서로 정리, **전체 복사**로 문자·메신저에 붙여넣기
- **발주서 미리보기**: 인쇄·PDF 저장용 화면

## 사용

1. 위 주소를 연다.
2. **새 품목 추가**에 병원 품목을 등록한다(예시 품목은 지우거나 수정).
3. **재고 목록**에서 입고·사용 때마다 수량을 맞춘다.
4. **자동 발주 목록**에서 거래처별 발주서를 복사해 주문한다.

> 브라우저 저장소를 지우면 입력한 데이터가 사라집니다. 다른 기기로 옮기려면 이 파일을 복사해 옮기는 대신, 각 기기에서 따로 입력하거나 **자동 발주 목록 → 전체 복사**로 내용을 남겨 두세요.
