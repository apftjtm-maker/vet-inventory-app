# 동물병원 재고 · 자동발주 체크

동물병원 재고를 품목별로 관리하고, 현재고가 안전재고 이하로 내려간 품목을 자동으로 판단해 거래처별 발주서를 만들어 주는 웹앱입니다.

## 이번 버전(v2)에서 바뀐 것

1. **실전 품목 프리셋 34종** — 공개된 국내 동물병원 유통 창구(블루벳·벳화점·온그린·수의사장터·펫토리·도매토피아·프로벳·로얄캐닌코리아·벳어스·IDEXX·팝애니랩)를 거래처로 넣고, 다빈도 품목 34종을 4개 카테고리로 나눠 기본 탑재했습니다. 개인정보·특정 병원명은 넣지 않았습니다.
   - 카테고리: **의약품 / 수액·소모품 / 사료·처방식 / 검사·기타**
   - 상단 카테고리 칩으로 바로 걸러 볼 수 있습니다.
   - 처음 열면 **8종이 안전재고 이하(발주 필요)** 로 잡혀 있어, 거래처별 자동 발주 묶음(블루벳·벳화점·펫토리·로얄캐닌코리아·IDEXX)을 바로 확인할 수 있습니다.
2. **품목별 수정(✏️)** — 품목명·카테고리·거래처(기존 거래처 자동완성)·규격·발주단위·현재고·안전재고·1회 발주수량·단가를 모달에서 바로 고칩니다.
3. **홈 화면 앱 아이콘 + 전체 화면(PWA)** — `manifest.webmanifest`, `icon-192/512.png`, `apple-touch-icon`, 서비스워커(`sw.js`)를 붙였습니다. 갤럭시 크롬·삼성 인터넷에서 **홈 화면에 추가**하면 주소창 없는 전체 화면으로 열립니다.
4. **백업 저장 / 불러오기** — `재고백업_YYYY-MM-DD.json`으로 내려받고, 다른 기기에서 그대로 복원합니다(공용 태블릿 ↔ 폰/PC 이전용).
5. **저장 키 분리** — 새 키 `vet-stock-auto-order-v2`를 씁니다. 이전 버전(`v1`) 데이터가 남아 있으면 화면 상단에 "이전 데이터 불러오기" 안내가 떠서, 원할 때만 가져옵니다.

## 화면

- **요약**: 전체 품목 수, 발주 필요 수, 정상 수, 예상 발주 금액
- **카테고리 칩**: 전체 / 의약품 / 수액·소모품 / 사료·처방식 / 검사·기타 (각 개수 표시)
- **재고 목록**: 품목·거래처, 현재고/안전재고, 수량 조절(-5 / -1 / 직접입력 / +1), ✏️ 수정, ✕ 삭제, 검색·거래처 필터·"발주 필요만"
- **새 품목 추가**: 카테고리 선택 포함
- **자동 발주 목록**: 현재고 ≤ 안전재고인 품목을 거래처별로 묶어 발주서로 정리, **발주서 복사 / 미리보기 / 입고 완료**
- **백업**: `⬇ 백업 저장`(JSON) / `⬆ 백업 불러오기`

## 사용

1. 위 주소를 연다.
2. 34종 프리셋을 병원 품목에 맞게 **✏️ 수정**하거나 지우고, 없는 품목은 **새 품목 추가**로 등록한다.
3. 입고·사용 때마다 수량을 맞춘다.
4. **자동 발주 목록**에서 거래처별 발주서를 복사해 주문한다.
5. 기기를 바꿀 때는 `⬇ 백업 저장` → 새 기기에서 `⬆ 백업 불러오기`.

> 입력한 값은 **그 브라우저의 localStorage**에만 저장됩니다(서버 전송 없음). 브라우저 저장소를 지우면 사라지므로, 중요한 시점에는 백업 파일을 받아 두세요.

> 표시된 단가는 2026년 11월 공개 소비자가·도매 공개가를 기준으로 넣은 **예시값**입니다. 실제 계약 단가로 수정해 쓰세요.
